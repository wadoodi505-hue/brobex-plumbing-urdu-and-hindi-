# Brobex Premium Plumbing

A modern, premium plumbing website built for a professional plumbing business.

The website focuses on a clean visual experience, strong branding, responsive design, and making it easy for customers to find services and get in touch.

### Features

* Premium & modern UI
* Fully responsive design
* Plumbing service sections
* Clear call-to-action buttons
* Mobile-friendly navigation
* Smooth interactions and animations
* SEO-friendly structure
* Fast and user-focused experience

## Urdu / Hindi language selector
The navigation includes an Urdu (default) / Hindi selector. The selected language applies to the navigation, selected homepage headings, and service-card labels. English brand names, phone numbers, and contact details remain unchanged. This is a partial localization pass; remaining page copy, FAQs, forms, and all detailed service descriptions still need translation before production release.
